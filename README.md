## 🔄 Auto-Updater Workflow (Future Updates)
When a new update or patch is needed in the future:
1. Go to [Releases](https://github.com/swiftprosystdm-png/Excel_Compare_Tool/releases) on GitHub.
2. Click **Draft a new release**.
3. Choose a tag version (e.g., `v1.11`, `v1.12`).
4. Attach the newly compiled `SPS_TDM_Excel_Comparison_Tool_V_1.xx.exe` as a release asset.
5. Click **Publish release**.

The desktop tool automatically checks for new releases on startup (and via the **"🔄 Check for Updates"** button in the app). It will notify the user, download the new executable, and update automatically!
